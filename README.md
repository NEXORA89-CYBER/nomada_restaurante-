# NÓMADA — Proyecto de portafolio #1

Landing page premium para un restaurante ficticio de Medellín.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Diseño responsive
- Menú filtrable por categorías
- Navegación móvil
- Formulario de reserva
- Generación de mensaje para WhatsApp
- Secciones de menú, experiencia y contacto

## Nota
NÓMADA es una marca ficticia creada exclusivamente para portafolio.
El número de WhatsApp y los datos del negocio son demostrativos y deben sustituirse por los del cliente real.
